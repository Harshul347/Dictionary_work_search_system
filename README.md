# Dictionary Word Search System

## About the Project
A C++ program designed to store, search, and display words from a simple dictionary.

## Features
- Store dictionary words
- Search for a word
- Display search results
- Organize words for efficient searching
- Handle missing words

## Technologies Used
- C++
- Data Structures

## Concepts Used
Strings, arrays or vectors, searching algorithms, and functions.

## How to Run
Compile the C++ source file and run the application.

## Learning Objective
To understand word searching, string handling, and efficient data organization.
